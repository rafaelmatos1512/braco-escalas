# Decisões

## Técnicas
- **Sem framework e sem build.** Projeto pequeno, roda em qualquer servidor estático, fácil de manter.
- **Acordes gerados por código**, não catalogados à mão: vale para qualquer nota/tipo e os filtros saem de graça. CAGED é exceção (formas fixas, por ser método de ensino).
- **PWA** em vez de app de loja: instalável, offline, sem custo. Dá para empacotar depois (Capacitor/TWA) se for vender em loja.

## Pendente: licença e modelo de negócio
- **MIT** — open source máximo; qualquer um pode copiar, inclusive para vender.
- **GPL-3.0 / AGPL-3.0** — open source, mas quem distribuir derivado tem que abrir o código.
- **Fechado (repo privado)** — se a ideia for vender sem concorrência do próprio código.
- **Híbrido** — núcleo aberto + versão "Pro" paga em repo privado.

Enquanto não decidir: repositório **privado** no GitHub e sem arquivo LICENSE (sem licença = todos os direitos reservados).
